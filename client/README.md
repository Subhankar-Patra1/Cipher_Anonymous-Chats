<h1 align="center">Cipher Client</h1>

The frontend for Cipher, built with React and Vite.

## 🚀 Features
- **Modern UI**: Styled with TailwindCSS and Framer Motion.
- **Real-time**: Socket.io integration for instant messaging.
- **Message Requests**: UI for managing incoming requests from unknown users.
- **Secure**: End-to-End Encryption support.
- **Premium UX**: Smooth transitions and responsive design.

## 🛠️ Tech Stack
- **React** (Vite)
- **TailwindCSS**
- **Socket.io-client**
- **Framer Motion**
- **React Router**

## 📦 Getting Started

### Prerequisites
- Node.js (v18+)

### Installation
1. Install dependencies:
```bash
npm install
```

2. Configure environment:
Create a `.env` file:
```env
VITE_API_URL=http://localhost:3000
```

3. Start development server:
```bash
npm run dev
```

## 🏗️ Build
To create a production build:
```bash
npm run build
```
The output will be in the `dist/` directory.
